# Desktop Tower Survivor — web build

Playable web build of **Desktop Tower Survivor**.

▶ **Play:** https://Kalgator.github.io/dts-web/
🎮 **Get the full game on Steam:** https://store.steampowered.com/app/4848460/

The desktop version is the real thing: the game runs on top of your desktop
instead of inside a browser tab, and it has cloud saves, leaderboards, guilds
and tournaments.
